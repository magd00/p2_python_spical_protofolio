Dinosaur Automation Simulation

To automate the original game without elgooG's AI mode, run the existing Python script on the desktop that displays the game. This browser page cannot control another site's tab or access your screen.

Run the original automation locally

The existing mian.py script opens https://elgoog.im/dinosaur-game/ in a Selenium-controlled Chrome window, captures desktop pixels with PIL/OpenCV, and sends real key presses with PyAutoGUI. It does not use the site's AI/Bot mode. The script must run on your computer because it needs access to your desktop.

cd projects\p12_automation_for_dinosaur_game
py -m pip install -r requirements.txt
py mian.py

Before running: install Chrome, keep the game window and desktop visible, and allow the script to use mouse/keyboard input. Stop it with Ctrl + C, hold S for one second, or close the browser window. The script clicks a fixed screen position during startup, so it assumes a desktop layout where the game is visible at that location.
